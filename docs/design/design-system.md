Источник: Figma «Додаток ZAG» (`MXOBup4Ilaxy5WE8wRyevL`, рабочая копия
`w3H4qazUL5GxhIm3MXnKzP`), страница `0:1`. Снято 2026-11-01 через Figma
MCP: `get_design_context` по узлам, прямое чтение свойств слоёв через
Plugin API (`use_figma`), выгрузка ассетов. Все значения ниже **проверены
по слоям**, кроме явно помеченных «предложение».

Файлы рядом: [`tokens.json`](tokens.json) (машиночитаемые токены),

**Масштабирование в коде.** Все px макета — для ширины 393. В `apps/web`
корневой `font-size` = `min(100vmin / 393 × 16px, 17.92px)`, а все длины в
CSS-модулях записаны в `rem` (1rem = 16 px при 393): на телефоне любой
ширины картинка пропорционально та же, что в макете (на 360 px всё × 0.916,
на 430 px × 1.094). `vmin` нужен ради ландшафтных экранов, где макет 852 × 393
меряется по высоте. Кап 17.92px (ширина 440) не даёт десктопу раздуть
лейаут. Новый CSS пишем сразу в `rem` = px / 16.

Дизайнер рисовал макеты шире и масштабировал до 393. Коэффициенты по
фреймам: Home 0.891, экраны интерактива 0.824, инструкция 0.779, Mission
0.927, график 0.845, связь потеряна 0.907. Отсюда дробные значения вроде
16.48 px. **Для вёрстки берём значения на 393** (первая колонка), «натив»
указан для понимания сетки дизайнера.

## 5. Эффект Glass и компонент «liquid glass»

В файле два разных «стекла».

### 5.1 Figma Glass (кнопки, переключатель языка)

Пилюли кнопок и языка — один прямоугольник с полупрозрачной заливкой и
эффектом Figma **Glass** (refraction) радиусом 3.3–3.7 px. Это даёт
лёгкое преломление фона и светлую кромку. В CSS точного аналога нет;
принятая аппроксимация:

```css
.glass-pill {
  background: rgba(217, 217, 217, 0.15);          /* 0 на Home, 0.20 у языка */
  backdrop-filter: blur(3px) saturate(1.15);
  -webkit-backdrop-filter: blur(3px) saturate(1.15);
  box-shadow:
    inset 0 1px 0 rgba(255, 255, 255, 0.35),
    inset 0 -1px 0 rgba(255, 255, 255, 0.08);
  border: 1px solid rgba(255, 255, 255, 0.22);     /* предложение, в Figma даёт Glass */
}
```

### 5.2 Компонент `liquid glass` (`8:19`, карточки)

Натив 387 × 631, радиус 24.67. Используется для карточек режимов,
инструкции, вариантов ширины/палитры и (в скрытом слое) кнопок. Структура:

1. Базовый прямоугольник: fill `rgba(217,217,217,0.01)`, **Background blur
   98.7** (в экземплярах 400 px шириной → 40 px, берём 40).
2. Восемь вложенных прямоугольников с тем же fill и **Layer blur 4.93**
   (→ 2 px), каждый вписан глубже предыдущего: inset 1.27 % → 3.17 → 5.71 →
   8.72 → 11.09 → 13.63 → 16.8 → 19.65 %. Дают мягкое свечение от края к
   центру.
3. Контурный прямоугольник: fill 0.01, **обводка 3.7 внутрь (→ 3 px)
   `rgba(255,255,255,0.10)`**, две внутренние тени: `#B3B3B3` offset
   (−17.3, −17.3) blur 8.6 spread −14.8 и `#FFF` offset (22.2, 22.2) blur 12.3
   spread −24.7. В экземплярах 400 px: (−14, −14, 7, −12) и (18, 18, 10, −20).

CSS для карточки 20 px радиуса:

```css
.glass-card {
  position: relative;
  border-radius: 20px;
  background: rgba(217, 217, 217, 0.01);
  backdrop-filter: blur(40px);
  -webkit-backdrop-filter: blur(40px);
  border: 3px solid rgba(255, 255, 255, 0.10);
  box-shadow:
    inset 18px 18px 10px -20px #fff,
    inset -14px -14px 7px -12px #b3b3b3;
}
/* свечение восьми слоёв, упрощённо */
.glass-card::before {
  content: ''; position: absolute; inset: 0; border-radius: inherit; pointer-events: none;
  box-shadow: inset 0 0 28px rgba(255, 255, 255, 0.05);
}
```

## 11. Чего нет в макете

- Состояния кнопок и выбранного варианта (§7).
- Заглушка для десктопа и экран «технические работы» (есть в ТЗ).
- Экран рисования UA/ENG отличается только текстом плашки.
- Fallback шрифтов: `system-ui`.

## 12. Как обновлять

Файл копии в команде grif energy (Pro) даёт квоту MCP; оригинал лежит в
Starter-команде с исчерпанной квотой. Для точных значений использовать
`get_design_context` по конкретным узлам и `use_figma` (read-only дамп
fills/strokes/effects), а не по целым экранам: целый экран не влезает в
таймаут и тратит квоту.
